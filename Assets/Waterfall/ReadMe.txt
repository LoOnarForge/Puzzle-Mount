





Hello, in this ReadMe you will understand how this shader works.

First, there are 2 main materials, the waterfall material and the river material. You must drag the river material to a Unity plane, and from there you can configure it as you wish. For the waterfall, you can either use the mesh that already exists in the project in the "Meshs" folder, or create your own mesh and modify it in the waterfall prefab located in the project.

Now, to make an object interactive with the waterfall is very simple: just drag the script located inside the "Script" folder to the object you want.
